# EGY MUSIC — إيجي ميوزك

مشغل موسيقى لأجهزة أندرويد بواجهة داكنة عربية.

## المميزات الموجودة
- قراءة الأغاني المحلية من الهاتف بعد منح إذن الصوت.
- عرض الأغاني وأغلفة الألبومات المتاحة، والبحث بالاسم أو الفنان.
- المفضلة مع حفظ الاختيارات على الجهاز.
- تشغيل وإيقاف وتخطي الأغاني، مع التشغيل العشوائي والتكرار.
- تشغيل في الخلفية مع إشعار تحكم ودعم أزرار شاشة القفل/جلسة الوسائط.
- زر معادل الصوت يفتح لوحة النظام إذا كان الجهاز يدعمها.
- مؤقت نوم: إيقاف التشغيل بعد 15 أو 30 أو 45 أو 60 أو 90 دقيقة، أو إلغاء المؤقت.

## بناء ملف APK
كل تحديث على فرع `main` يشغّل GitHub Actions لبناء نسخة Debug APK.
1. افتح تبويب Actions في المستودع.
2. اختر أحدث عملية بناء مكتملة بنجاح.
3. نزّل `EGY-MUSIC-debug-APK` من قسم Artifacts وفك الضغط.
4. ثبّت `app-debug.apk` على هاتف أندرويد. قد تحتاج السماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة
هذه نسخة Debug موقعة تلقائيًا بمفتاح التطوير وليست إصدار متجر موقّع بمفتاح نشر خاص. تم بناء التطبيق عبر GitHub Actions، لكن لا يمكن ضمان عمله على كل جهاز من دون اختبار عملي على ذلك الجهاز. توافر معادل الصوت وأغلفة الألبومات يعتمد على الجهاز وملفات الموسيقى.
