# EGY MUSIC — إيجي ميوزك

مشغل موسيقى محلي لأجهزة أندرويد بواجهة داكنة عصرية مستوحاة من تطبيقات مشغلات الموسيقى الحديثة، مع الحفاظ على هوية EGY MUSIC.

## المميزات
- مكتبة موسيقى محلية مع أغلفة الألبومات المتاحة.
- بحث باسم الأغنية أو الفنان أو الألبوم.
- تصفح حسب الأغاني والألبومات والفنانين والمفضلة.
- قوائم تشغيل مخصصة: إنشاء، إعادة تسمية، حذف، وإضافة الأغاني بالضغط المطوّل على الأغنية.
- تشغيل وإيقاف وتخطي الأغاني، وتشغيل عشوائي وتكرار.
- تشغيل في الخلفية مع إشعار تحكم وجلسة وسائط لشاشة القفل.
- معادل الصوت إذا كانت لوحة النظام مدعومة.
- مؤقت نوم لإيقاف الموسيقى تلقائيًا.
- تفضيلات المفضلة وقوائم التشغيل محفوظة محليًا على الجهاز.

## تنزيل APK
كل تحديث على فرع `main` يشغّل GitHub Actions لبناء نسخة Debug APK.
1. افتح تبويب Actions في المستودع.
2. اختر أحدث عملية بناء مكتملة بنجاح.
3. نزّل `EGY-MUSIC-debug-APK` من قسم Artifacts وفك الضغط.
4. ثبّت `app-debug.apk` على هاتف أندرويد.

## ملاحظات
هذه نسخة Debug وليست إصدار متجر موقّع بمفتاح نشر خاص. لا تتضمن هذه النسخة خدمة بث موسيقى عبر الإنترنت أو قاعدة بيانات كلمات أغاني متصلة بالإنترنت. توافر معادل الصوت وأغلفة الألبومات يعتمد على الجهاز والملفات الموجودة عليه. يلزم اختبار عملي على الهاتف للتأكد من التوافق مع إصدار أندرويد الخاص به.
