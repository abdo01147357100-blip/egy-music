# EGY MUSIC

مشغل موسيقى أندرويد بسيط بواجهة داكنة، يعرض الملفات الصوتية الموجودة على الجهاز ويسمح بتشغيلها وإيقافها والتنقل بين الأغاني.

## البناء التلقائي

كل تحديث على فرع `main` يشغّل GitHub Actions لبناء نسخة Debug APK. ويمكن تشغيل البناء يدويًا من تبويب **Actions** باختيار **Build EGY MUSIC APK** ثم **Run workflow**.

بعد نجاح البناء:
1. افتح تبويب **Actions** في المستودع.
2. اختر أحدث عملية بناء ناجحة.
3. من قسم **Artifacts** نزّل `EGY-MUSIC-debug-APK`.
4. فك ضغط الملف لتحصل على `app-debug.apk)، ثم انقله إلى هاتف أندرويد وثبّته.

## المميزات الحالية

- قراءة الأغاني المحلية بعد إذن المستخدم.
- قائمة أغاني مرتبة حسب الاسم.
- تشغيل وإيقاف مؤقت والانتقال للأغنية التالية أو السابقة.
- واجهة داكنة باسم EGY MUSIC.

## ملاحظات

هذه نسخة أولية قابلة للبناء وليست إصدارًا نهائيًا مختبرًا على مجموعة واسعة من الأجهزة. التشغيل في الخلفية مع خدمة وسائط وإشعار تحكم، وصور الألبومات، والبحث، والمفضلة، واختبارات الأجهزة ما زالت ضمن التطوير.
